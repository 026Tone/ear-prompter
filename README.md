# Ear Prompter

Paste a script and this page reads it into your earbud one line at a time, with a pause after each line so you can say it to camera.
Runs fully in the browser (voices: Kokoro 82M, Apache-2.0; Piper "joe", CC0 data). Your scripts never leave your phone.

Source and build script: private workspace repo (ear-prompter/). This repo only holds the built page.
